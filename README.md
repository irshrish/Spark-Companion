# Spark: Advanced Android Floating Companion

An open-source Android companion powered by **Google AI Studio (Gemini 2.5 Flash)** with:
- **Always-on floating avatar** over other apps with drag gestures & squish physics.
- **Multimodal Screen Vision** (takes screenshot and sends to Gemini to analyze your current screen).
- **Native Device Function Calling** (battery level, flashlight on/off).
- **Automated Cloud Build via GitHub Actions** (no local Android Studio needed!).

## How to Build the APK using GitHub Actions (Cloud)
1. Create a new repository on [GitHub](https://github.com/new).
2. Upload all the files from this folder to the repository.
3. GitHub Actions will automatically start building the APK (under the **Actions** tab).
4. When finished (typically 2-3 minutes), click the completed run and download **Spark-Companion-Debug-APK**.
5. Install the APK on your Android phone, enter your Google AI Studio API key, and tap **Save & Spawn Companion**!
